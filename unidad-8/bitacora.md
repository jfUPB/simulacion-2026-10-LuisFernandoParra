# Herramienta elegida

La pieza fue desarrollada utilizando:

- **Three.js** para renderizado 3D en tiempo real.
- **GLTFLoader** para importar modelos 3D.
- **JavaScript** como lenguaje principal.
- **Web Audio API / THREE.AudioAnalyser** para análisis reactivo al audio.
- **HTML5 Video** para la transición cinematográfica final.
- **OrbitControls** para manejo inicial de cámara.
- Modelos `.glb` y composición audiovisual inspirada en conciertos y visuales psicodélicos contemporáneos.

---

# Sistema transferido

Se tomó como referencia el sistema visual y narrativo de:
- experiencias inmersivas de conciertos,
- visuales de música psicodélica,
- simulaciones espaciales cinematográficas,
- y sistemas de transición audiovisual sincronizados con música.

La lógica de transferencia consistió en transformar:
- un entorno cotidiano (salón de clases)
- hacia un viaje espacial abstracto y emocional.

El proyecto traduce el concepto de “escape mental” usando:
- movimiento de cámara,
- color,
- partículas,
- distorsión visual,
- y sincronización sonora.

# Contexto profesional concreto

La pieza se plantea como una experiencia audiovisual interactiva cercana a:

# Concepto visual

La pieza representa un proceso de transición psicológica:

1. Inicio en un espacio académico cotidiano.
2. Distorsión progresiva de la realidad mediante sonido y luz.
3. Ruptura espacial y viaje abstracto.
4. Exploración cósmica inmersiva.
5. Aproximación a un planeta simbólico.
6. Transición hacia material audiovisual real.

Visualmente se trabajó con:
- luces RGB,
- desenfoques,
- partículas,
- movimiento orbital,
- escalas espaciales,
- y composición cinematográfica.

# Explicación de la transferencia

La transferencia consiste en adaptar sistemas cinematográficos y visuales de conciertos al contexto de una pieza interactiva web en tiempo real.

Elementos transferidos:
- lenguaje audiovisual psicodélico,
- transiciones inmersivas,
- movimiento de cámara cinematográfico,
- sincronización musical,
- composición espacial.

La pieza convierte referencias de conciertos y visuales musicales en una experiencia interactiva desarrollada en navegador.

# Mapa de decisiones

## Decisiones principales

### Se descartó:
- usar múltiples planetas,
- múltiples escenas complejas,
- simulaciones físicas avanzadas.

### Se priorizó:
- estabilidad visual,
- narrativa clara,
- sincronización musical,
- transición cinematográfica.

### Decisión importante
Se reemplazó el cierre negro por:
- transición directa a video fullscreen.

Esto permitió:
- mayor estabilidad,
- mejor narrativa,
- menos errores técnicos,
- y un resultado más cinematográfico.
